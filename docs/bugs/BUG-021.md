# BUG-021 – Calendar accepts events dated 9999 or 1900

| Field | Value |
|---|---|
| Module / Category | Other (calendar) / Validation |
| Severity / Priority | Low / Medium |
| Reported by / Fixed by | Mayank |
| Status | Fixed |

## How it was found
Probed `add_event` with `9999-01-01` and `1900-01-01`: both saved, and stay in the "All events" list forever. Leave dates already have a date window (BUG-006); events did not.

## Root cause
`validate_event_date` only checked the `YYYY-MM-DD` format.

## Fix
`app/utils/validation.py`: reject event dates more than 5 years (`EVENT_WINDOW_YEARS`) from today.

## Test
`tests/test_bug_fixes.py::test_bug_021_event_dates_limited_to_a_sensible_window` (fails without the fix). Full suite: 219 tests OK.
