# BUG-022 – Calendar duplicate check ignores case and inner spaces

| Field | Value |
|---|---|
| Module / Category | Other (calendar) / Data Integrity |
| Severity / Priority | Low / Low |
| Reported by / Fixed by | Mayank |
| Status | Fixed |

## How it was found
Same probe as BUG-021: "Fest" and "FEST" were both saved on one date, and "Fest   Night" kept its extra spaces.

## Root cause
Titles were trimmed only at the ends, and the duplicate query compared titles exactly.

## Fix
`validate_event_title` collapses inner whitespace; `event_service.add_event` compares `LOWER(title)`. (SQLite's `LOWER` is ASCII-only, so non-ASCII titles still compare case-sensitively.)

## Test
`tests/test_bug_fixes.py::test_bug_022_event_titles_normalised_and_duplicates_ignore_case` (fails without the fix). Full suite: 220 tests OK.
