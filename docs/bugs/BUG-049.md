# BUG-049 – Contact numbers in everyday written forms are rejected

| Field | Value |
|---|---|
| Module / Category | Student / Validation |
| Severity / Priority | Medium / Medium |
| Reported by / Fixed by | Mayank |
| Status | Fixed |

## How it was found
Probing the validators with realistic input. `+919876543210`, `098765 43210` and `98765-43210` all failed, with messages that did not tell the user what to change. Phone numbers are copied from phones and forms in exactly these shapes, so registration and student sign-up failed for ordinary input.

## Fix
`validate_contact_number` removes spaces, hyphens and brackets and a `+91`, `0091`, `91` (12 digits) or `0` (11 digits) prefix, then applies the unchanged rule: ten digits, starting with 6-9. The stored value is always the plain ten digits, so the sign-up match (BUG-038) compares like with like.
