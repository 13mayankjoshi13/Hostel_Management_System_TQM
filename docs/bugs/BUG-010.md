# BUG-010 — Student name keeps extra spaces and tabs, and accepts names with no letters

| Field | Value |
|---|---|
| Module / Category | Student / Validation |
| Severity / Priority | Low / Medium |
| Status | Fixed (close it in the Bug screen after re-testing) |

## How it was found
Fourth round of exploratory testing: a script fed unusual names to `validate_student_name` and printed what came back.

```
'Ravi  Kumar'   -> 'Ravi  Kumar'     (two spaces kept)
'Jean<tab>Luc'  -> 'Jean<tab>Luc'    (tab kept)
'...'           -> accepted           (no letters)
```

Stored like this, "Ravi  Kumar" and "Ravi Kumar" look like different people, sort differently in the new student sort, and tabs can break CSV and table display.

## Root cause
`validate_student_name` only trimmed the two ends and allowed any space character plus `. ' -`, with no check that the name contains a letter.

## Fix
`app/utils/validation.py`, `validate_student_name`:
- every run of whitespace (spaces, tabs, newlines) becomes one space: `" ".join(name.split())`;
- a name must contain at least one letter.

Names such as `O'Brien`, `Anne-Marie` and `Km. Komal` are still accepted.
