# BUG-020 – Evidence log CSVs run user text as a spreadsheet formula

| Field | Value |
|---|---|
| Module / Category | Other (logging) / Security |
| Severity / Priority | Medium / Medium |
| Reported by / Fixed by | Mayank |
| Status | Fixed |

## How it was found
Logged a bug titled `=HYPERLINK("http://x","a")` and opened the raw `defect_log.csv`: the text was written verbatim. Excel evaluates a cell starting with `=`, `+`, `-` or `@` (CSV formula injection), and these logs are the project's evidence files that get opened in Excel.

## Root cause
`_append_row` wrote user-supplied text without checking for formula prefixes.

## Fix
`app/utils/logging_service.py`: `_neutralise` prefixes such text with an apostrophe; applied in the shared `_append_row`, so the error, audit and defect logs are all covered.

## Test
`tests/test_bug_fixes.py::test_bug_020_log_csv_neutralises_formula_text` (fails without the fix). Full suite: 218 tests OK.
