# BUG-044 – Names can start with '-'; the allotment CSV export runs such text as a formula

| Field | Value |
|---|---|
| Module / Category | Student / Validation |
| Severity / Priority | Medium / Medium |
| Reported by / Fixed by | Mayank |
| Status | Fixed |

## How it was found
Probing the places user text leaves the application. The evidence logs neutralise formula text (BUG-020), but the allotment-list export did not, and `validate_student_name` accepted `-`, `'` and `.` anywhere, including as the first character.

## Fix
`validate_student_name` requires the first character to be a letter. `export_allocation_list` passes every cell through `_neutralise`, so names saved before the rule are also safe.

## Test
`tests/test_bug_fixes.py::test_bug_044_*` (fails without either half of the fix). Full suite: 255 tests OK (18 UI tests skipped without a display).

## Not covered
Other free text (complaint descriptions, event titles) is not exported to CSV today; any new export must use the same neutralising.
