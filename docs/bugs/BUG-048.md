# BUG-048 – Devanagari names are rejected; the allotment CSV is garbled in Excel

| Field | Value |
|---|---|
| Module / Category | Student / Validation |
| Severity / Priority | High / High |
| Reported by / Fixed by | Mayank |
| Status | Fixed |

## How it was found
Known gap since earlier batches. Real hostel records include Hindi names. `'मयंक जोशी'` failed with "Student name contains invalid characters": vowel signs and the nasal mark are Unicode combining marks, and `isalpha()` is false for them, so most Devanagari names were unusable. Names that did get through would also show as garbage when the allotment CSV was opened in Excel, which needs a byte-order mark to read UTF-8.

## Fix
- `validate_student_name`: combining marks (Unicode category M*) are allowed, still not as the first character; names are normalised to NFC so the same name typed two ways is one name.
- `export_allocation_list`: written with `utf-8-sig`.
- `tests/test_leave.py` reads the export with `utf-8-sig`, as Excel does.

## Test
