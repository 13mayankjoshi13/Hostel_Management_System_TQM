# BUG-018 – Student stays "On Leave" after the room is released

| Field | Value |
|---|---|
| Module / Category | Allocation / Data Integrity |
| Severity / Priority | Medium / Medium |
| Reported by / Fixed by | Mayank |
| Status | Fixed |

## How it was found
Probed a student with an open leave, then released their allocation. The leave stayed "On Leave" with no active room, and "mark returned" was the only way to clear it.

## Root cause
`release_allocation` updated only the allocation row and never touched the student's open leave.

## Fix
`app/services/allocation_service.py`: in the same transaction as the release, set the student's open leave to `Returned` with a timestamp.

## Test
`tests/test_bug_fixes.py::test_bug_018_releasing_a_room_closes_the_open_leave` (fails without the fix). Full suite: 216 tests OK.
