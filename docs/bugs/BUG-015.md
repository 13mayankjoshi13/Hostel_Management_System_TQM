# BUG-015 – Sign-up dialog allows a second submit after success

| Field | Value |
|---|---|
| Module / Category | UI / UI/UX |
| Severity / Priority | Low / Medium |
| Reported by / Fixed by | Mayank |
| Status | Fixed |

## How it was found
Drove the sign-up dialog with a real Tk window: valid request → green "Request sent". Clicking **Request Account** again replaced it with a red "Username 'testkid' is already taken", which looks like the request failed.

## Root cause
After success only the entry fields were disabled; the submit button stayed active.

## Fix
`app/screens/signup_screen.py`: keep a reference to the submit button, disable it after success, and relabel Cancel as Close.

## Test
`tests/test_signup_ui.py::test_bug_015_success_locks_the_form_and_keeps_the_message` (fails without the fix, passes with it). Full suite: 213 tests OK.
