# BUG-008 — Allotment list export sorts rooms as text (A10 before A2)

| Field | Value |
|---|---|
| Module / Category | Allocation / Functional |
| Severity / Priority | Low / Medium |
| Status | Fixed (close it in the Bug screen after re-testing) |

## How it was found
Third round of exploratory testing, this time on the export and the quality summary. Four rooms were allocated and the allotment list exported:

```
Room
A1
A10     <- expected after A2
A2
B3
```

With a 56-student hostel the list reaches A10 and beyond, so the printed allotment list would be out of order.

## Root cause
`export_allocation_list` sorted by `room_number` as a string, which compares character by character ("A10" < "A2").

## Fix
`app/services/allocation_service.py`: new `_room_order` sorts by block letters, then the numeric part, then the full room number. Result: A1, A2, A10, AB1, B3.

Only the export changed. The on-screen Room and Allocation lists stay newest-first, as before.

## Test
`tests/test_bug_fixes.py` — `test_bug_008_export_rooms_in_natural_order`. Full suite: 170 tests pass.

## Tracker entry
`python -m app.database.log_bugs` adds BUG-008 and skips the ones already logged.
