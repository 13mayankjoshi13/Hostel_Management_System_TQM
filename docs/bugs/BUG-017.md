# BUG-017 – Malformed student/room IDs accepted (True, 1.9)

| Field | Value |
|---|---|
| Module / Category | Allocation, Complaint, Leave / Validation |
| Severity / Priority | Medium / Medium |
| Reported by / Fixed by | Mayank |
| Status | Fixed |

## How it was found
Probed the services with odd inputs: `create_complaint(1.9, ...)` was saved against student 1 and `True` was treated as ID 1.

## Root cause
IDs were converted with `int()`, which truncates floats and accepts booleans, so a malformed ID silently acted on the wrong record.

## Fix
`validate_record_id` in `app/utils/validation.py` rejects bools and non-whole floats (whole numbers and numeric strings still work). Used in `complaint_service.create_complaint`, `leave_service.record_leave` and `allocation_service.allocate_room`.

## Test
`tests/test_bug_fixes.py::test_bug_017_record_ids_reject_bool_and_fractions` (fails without the fix). Full suite: 215 tests OK.
