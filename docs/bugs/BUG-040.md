# BUG-040 – The log-in window cannot be closed, so the application cannot be quit from it

| Field | Value |
|---|---|
| Module / Category | UI / Functional |
| Severity / Priority | High / High |
| Reported by / Fixed by | Mayank |
| Status | Fixed |

## How it was found
Reviewing window handling: `LoginScreen` bound its close button to a no-op ("must log in to proceed"). The log-in window is the first thing shown, and it comes back after Log out and after the idle log-out (BUG-033), so a user who just wants to quit has no way to: the X does nothing and the main window is hidden. The only way out was to kill the process. Separately, closing the main window while logged in left no log-out entry in the audit log.

## Root cause
Close requests were ignored or unhandled.

## Fix
- `login_screen.py`: the X button quits the application (`on_close_request`).
- `main_window.py`: `exit_app` logs the user out (audit entry, session cleared) and then closes.

## Test
`tests/test_close_ui.py` (display required): closing the log-in window ends the application; closing the main window logs out. The first fails without the fix. Full suite: 251 tests OK.

## Not covered
Closing the sign-up dialog is unchanged (it already closes itself).
