# BUG-016 – Calendar does not jump to the month of a newly added event

| Field | Value |
|---|---|
| Module / Category | UI / UI/UX |
| Severity / Priority | Low / Medium |
| Reported by / Fixed by | Mayank |
| Status | Fixed |

## How it was found
Drove the Calendar screen as an editor: added an event dated in another month. "Event added." appeared, but the calendar kept showing the current month, so the new event was not visible.

## Root cause
`on_add` refreshed the calendar without changing the month it displays.

## Fix
`CalendarWidget.show_date(day)` sets year, month and selected day and redraws; `CalendarScreen.on_add` calls it with the saved event's date.

## Test
`tests/test_calendar_ui.py::test_bug_016_adding_event_in_another_month_jumps_to_it` (fails without the fix). Full suite: 214 tests OK.
