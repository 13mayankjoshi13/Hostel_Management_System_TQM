# BUG-009 — Quality fix rate rounds halves to even (12.5% shows as 12%)

| Field | Value |
|---|---|
| Module / Category | Other (quality summary) / Functional |
| Severity / Priority | Low / Low |
| Status | Fixed (close it in the Bug screen after re-testing) |

## How it was found
Same run as BUG-008. Eight bugs were logged and one was taken to Fixed:

```python
get_quality_summary()["fix_rate_pct"]   # 12  (1 / 8 = 12.5%, expected 13)
```

Three fixed of eight (37.5%) would show 38, so the same rule rounds some halves up and others down.

## Root cause
`get_quality_summary` used `round(fixed / total * 100)`. Python's `round()` rounds exact halves to the nearest even number (banker's rounding), which is not what a reader expects from a percentage.

## Fix
`app/services/quality_service.py`: the percentage uses integer half-up rounding, `(fixed * 200 + total) // (2 * total)`. With no bugs it is still 0.

The Pareto cumulative percentages use `round(..., 1)` on float ratios and were not changed.

## Test
`tests/test_bug_fixes.py` — `test_bug_009_*` (1/8 → 13, 3/8 → 38, 0/8 → 0, 8/8 → 100, 1/3 → 33, 2/3 → 67, no bugs → 0). Full suite: 172 tests pass.
