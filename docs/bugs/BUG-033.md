# BUG-033 – Logged-in session never times out

| Field | Value |
|---|---|
| Module / Category | UI / Security |
| Severity / Priority | High / Medium |
| Reported by / Fixed by | Mayank |
| Status | Fixed |

## How it was found
Reviewed the session lifecycle: `session.py` holds the logged-in user for the life of the process, and nothing ends it. On a shared hostel-office computer, a warden or administrator who walks away leaves every student record (and the Users screen) open.

## Root cause
No inactivity limit.

## Fix
- `app/utils/idle.py`: `IdleTracker`.
- `app/config.py`: `IDLE_TIMEOUT_MINUTES = 15`.
- `main_window.py`: mouse, key and wheel activity resets the timer; the existing one-second tick checks it. On expiry the user is logged out, an `IdleLogout` audit entry is written, the login window comes back and a message explains why. Pending clock-tick timers are now cancelled when the window closes.

## Test
`tests/test_idle.py`: tracker unit test and a real-window test (idle session is logged out, active one is not; fails without the fix). Full suite: 237 tests OK.

## Not covered
The 15-minute limit is a default, not a user setting.
